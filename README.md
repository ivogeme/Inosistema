Inosistema

Um projeto experimental de desenvolvimento de um núcleo pequeno, escrito em C e Assembly, com foco inicial em computadores x86 antigos.

Objetivo

Desenvolver um núcleo independente de distribuições Linux, com uma base simples e enxuta para explorar a inicialização do computador, o acesso a hardware e a execução de código em sistemas antigos.

Estado do projeto

Versão: 0.1.0-prototype
Estado: experimental, em desenvolvimento.

A primeira etapa pretende estabelecer:

- Inicialização por bootloader.
- Entrada no código C.
- Comunicação serial.
- Shell de comandos básico.

Plataforma-alvo

A arquitetura inicial é x86 em modo real. A compatibilidade com o IBM PC 5150 e seu processador Intel 8088 ainda precisa ser desenvolvida e testada.

Limitações atuais

- Sistema de arquivos persistente ainda não implementado.
- Leitura e gravação de arquivos ainda não implementadas.
- Execução de programas a partir do disco ainda não implementada.
- Compatibilidade com hardware físico ainda não validada.

Desenvolvimento

O projeto está em fase de protótipo. Funcionalidades serão implementadas e testadas progressivamente.

Filosofia 

Uma barra de sistema que não depende de internet extremamente leve feita em caso o mundo digital colapsar.
E a gente precisa refazer os computadores, ele será uma alternativa por funcionar em chips simples você pode montar o seu sistema operacional de sobrevivência com ele atualmente, ele muito focado no X86 mas futuramente, eu quero que ele seja possível de você adaptar a ele para chip de 8 a 16 bits
